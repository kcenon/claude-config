Red Team variant I: `bash -c '...'` (and `sh -c`, `zsh -c`, etc.) hides its payload behind a single string argument. Since issue #964 the guard tokenizes that payload and applies the same rules to it instead of denying every inline shell, so this case is denied because its payload is `rm -rf /`. A payload the guard cannot inspect (a bare `$VAR`, unbalanced quotes, nesting past the depth bound) is still denied.
